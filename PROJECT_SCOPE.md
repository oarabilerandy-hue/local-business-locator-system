# Project scope — Local Business Locator System

Based on the Botho University project brief.

## Core objectives
1. Discover local services by category, keyword, and location.
2. Display provider locations and directions.
3. Compare provider prices.
4. Support customer ratings and reviews.
5. Let providers create profiles, list services, update prices, and manage availability.
6. Keep the app lightweight and accessible on low-end smartphones.
7. Improve visibility for small and informal local businesses.

## MVP boundaries
This prototype uses seeded demonstration listings. New listings and review interactions are held in memory and are not saved after restarting. Sample providers, ratings, prices, and distances must not be treated as verified real-world data. Persistent database, authentication, live GPS/maps, moderation, and signed production release remain future work.
